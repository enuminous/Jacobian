# Jacobian Zoo audit protocol

Target: `enuminous/Jacobian@1a4a649c77df4d869cc88d48d76a46fa489c3725`.
Audit date: 2026-11-05. This is a retrospective audit. The successful 2026-11-04 CI run and the source have already been inspected. The following criteria are fixed before executing the new controls; this is not a preregistered scientific experiment.

1. Re-run the pinned source fetch in isolation. PASS requires exact archive identity and both supplied digest checks. A corrupted archive must be rejected. Seed one harmless unlisted file before extraction; an exact-directory integrity gate would remove it or reject it. Retention with a PASS is a bounded integrity failure, not evidence of a compromised historical run.
2. Axiom parser: accept one exact terminal declaration with the standard allowlist or no axioms. Reject missing, truncated, wrong-name, unexpected-axiom, duplicate and contradictory reports. Each case has its expected acceptance fixed in `checks.py`. No adversarial report is presented as real Lean output.
3. Independently implement arithmetic in F₂[x,y]. Compare formal derivatives, determinant, compact identities, hidden cubic, elimination and the explicit collision with the source formulas. Require exact polynomial equality. Remove the y term of Q as a negative control; it must break determinant one. At (1,0), evaluate the characteristic-zero derivative determinant as a domain negative control.
4. Scan all released Lean source after stripping comments/strings for `sorry`, `admit`, declared axioms and unsafe/native escape markers; build the local import graph and check for cycles. This is source screening, not a replacement for the kernel.
5. WEASEL runs its pinned bounded input search against the actual baseline parser, with one changed text field and rejection failures as weakness. Three repeats per finding must agree. ELEPHANT preserves the archive → CI → audit chronology without treating prior receipts as a new proof. SALMON traces the report → CI → frozen archive lineage, using unit edges as bookkeeping rather than evidence probabilities. CIRCUS checks a broad certification claim against explicit unresolved semantic/independence obligations. MONSTER applies its fixed gate to the parser controls with all cases required and a rejection/correct-acceptance tolerance of 1.
6. All 52 entries in the current Tortoise illustration inventory are accounted for. Historical main-sequence kernels are pinned to Monolithic-Zoo-Lean4 `8b22841ffcf44e41451e7696335bf6a6ae8f222e`. A missing input, undefined operator or domain mismatch is UNRESOLVED with an applicability reason; never invent data to obtain a Zoo score. Raw N/A from a source gate maps to UNRESOLVED, preserving the raw value.

The audit will publish failures even when the proof replay is green. No overall percentage or majority vote can turn evidence gaps into a mathematical certification.

F-01 · medium severity

The parser accepts ambiguity.

The baseline axiom parser accepts four invalid forms:

  1. A different theorem name ending in the target name
  2. A duplicate allowed report
  3. An allowed report followed by a sorryAx report
  4. Unexpected trailing text

Extraction leaves stale input.

The source hash gates correctly reject a corrupt archive. But extracting into an existing directory leaves an unlisted file behind while reporting PASS.

The sentinel was harmless and was not imported. This exposes a narrower integrity guarantee; it does not demonstrate a compromised historical build.
